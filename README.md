## 🚀 Overview

AI Email Writer is a frontend application that enables users to generate  
intelligent, context-aware email replies using an AI backend.  
Built with a focus on simplicity, speed, and real-world usability.

---

## 🏗 Architecture


User (Browser)
↓
React Frontend (Netlify)
↓
Spring Boot API (Render)
↓
Groq AI (LLM Processing)
